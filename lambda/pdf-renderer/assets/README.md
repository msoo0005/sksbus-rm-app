# PDF renderer assets

- `texgyreheros-regular.otf`, `texgyreheros-bold.otf`: TeX Gyre Heros 2.004,
  a free Helvetica-equivalent from GUST (https://www.gust.org.pl/projects/e-foundry/tex-gyre/heros),
  distributed under the GUST Font License. The spec asks for these to be embedded so
  every PC and printer shows the same letters.
- `SKSCHASSIS_LOGO_BLACK_AND_WHITE.svg`: **add this file** (the black-and-white SKS
  Chassis logo). Until it is here, the header prints "SKS CHASSIS" as text.
